Classes e objetos

Entenda a diferença entre objeto e classe em JavaScript e como usar a sintaxe moderna.

O que é um objeto?

Um objeto é uma coleção de pares chave: valor que representa dados e comportamento. Objetos podem ter propriedades e métodos e são muito usados para modelar coisas no código.

O que é uma classe?

Uma classe é um molde para criar objetos com a mesma estrutura. Ela define como os objetos serão construídos e quais métodos eles terão.

Exemplo de classe

class Pessoa {
  constructor(nome, idade) {
    this.nome = nome;
    this.idade = idade;
  }

  apresentar() {
    return `Olá, eu sou ${this.nome} e tenho ${this.idade} anos.`;
  }
}

const ana = new Pessoa('Ana', 28);
console.log(ana.apresentar());

Como criar objetos diretamente

const livro = {
  titulo: 'JavaScript Básico',
  autor: 'Maria',
  paginas: 150,
  ler() {
    console.log(`Lendo ${this.titulo}`);
  }
};

livro.ler();

Herança com classes

Com extends, uma classe pode herdar propriedades e métodos de outra classe. 

class Animal {
  constructor(nome) {
    this.nome = nome;
  }

  falar() {
    console.log(`${this.nome} faz um som.`);
  }
}

class Cachorro extends Animal {
  falar() {
    console.log(`${this.nome} late.`);
  }
}

const rex = new Cachorro('Rex');
rex.falar();

Resumo

  • Objeto é uma estrutura de dados com propriedades e métodos.
  • Classe é um padrão para criar objetos semelhantes.
  • new instancia um objeto a partir de uma classe.
  • Herança permite compartilhar comportamento entre classes.
