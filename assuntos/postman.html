Postman

Uma ferramenta para testar requisições HTTP e trabalhar com APIs de forma visual.

O que é o Postman?

O Postman é um aplicativo usado para criar, testar e organizar requisições HTTP. Ele facilita enviar solicitações GET, POST, PUT, DELETE e ver as respostas.

Por que usar?

  • Testar APIs sem precisar escrever código.
  • Salvar requisições e reutilizar headers, corpo e parâmetros.
  • Visualizar respostas em JSON, XML ou texto.
  • Trabalhar com autenticação, variáveis e coleções.

Solicitação básica

No Postman, você escolhe o método HTTP, coloca a URL e adiciona headers ou corpo. 

GET https://api.exemplo.com/usuarios
Accept: application/json

// Depois clique em Send para ver a resposta

Autenticação

O Postman permite configurar autenticação básica, Bearer Token e outros tipos em cada requisição. Isso é útil para testar endpoints protegidos por Authorization.

Coleções e variáveis

Coleções agrupam várias requisições relacionadas. Variáveis tornam mais fácil trocar URLs, headers, tokens e outros dados sem precisar editar cada requisição.

No Postman, você pode criar variáveis em diferentes escopos:

  • Global: disponíveis em qualquer requisição do Postman.
  • Collection: disponíveis apenas nas requisições dentro de uma coleção.
  • Environment: úteis para alternar entre ambientes como desenvolvimento, teste e produção.
  • Local: usadas somente na requisição atual.

Para usar uma variável, escreva o nome entre chaves duplas: {{nome_da_variavel}}. 

{{base_url}}/login
Authorization: Bearer {{token}}

Exemplo: se {{base_url}} for https://api.exemplo.com e {{token}} for abc123, o Postman envia: 

GET https://api.exemplo.com/login
Authorization: Bearer abc123

Variáveis de ambiente são especialmente úteis para mudar de um ambiente para outro sem alterar a URL ou token manualmente.

Resumo

Use o Postman para testar APIs durante o desenvolvimento, validar respostas e preparar requisições antes de implementar o código.
