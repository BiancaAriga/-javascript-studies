Manipulação de JSON

JSON (JavaScript Object Notation) é um formato leve para troca de dados. Em JavaScript, usamos JSON.parse() e JSON.stringify() para converter entre strings JSON e objetos.

Parse — converter string JSON em objeto

Use JSON.parse(). Envolva em try/catch porque a string pode ser inválida.

const json = '{"titulo":"Livro A","ano":2020}';
try {
  const obj = JSON.parse(json);
  console.log(obj.titulo); // "Livro A"
} catch (e) {
  console.error('JSON inválido', e);
}

Stringify — converter objeto em string JSON

Use JSON.stringify(). Você pode passar um replacer ou um valor de espaço para formatar a saída.

const obj = { titulo: 'Livro A', ano: 2020 };
const jsonStr = JSON.stringify(obj);
const pretty = JSON.stringify(obj, null, 2); // null = sem replacer, 2 = indentação de 2 espaços
console.log(pretty);

O segundo parâmetro null diz para não filtrar ou transformar propriedades. O terceiro parâmetro 2 adiciona espaços para deixar o JSON mais legível.

Trabalhando com respostas de API (fetch)

Com fetch, chame response.json() para obter o body já convertido em objeto.

fetch('https://fakerapi.it/api/v1/books?_quantity=5')
  .then(response => {
    if (!response.ok) throw new Error('Erro na resposta');
    return response.json();
  })
  .then(data => {
    console.log(data);
  })
  .catch(err => console.error(err));

// Com async/await
async function listar() {
  try {
    const res = await fetch('https://fakerapi.it/api/v1/books?_quantity=5');
    if (!res.ok) throw new Error('Erro na requisição');
    const json = await res.json();
    console.log(json);
  } catch (err) {
    console.error(err);
  }
}
listar();

Reviver e Replacer

O reviver no parse permite transformar valores durante a conversão. O replacer no stringify permite filtrar ou modificar valores.

// reviver: converte strings ISO para Date
const s = '{"data":"2023-01-01T12:00:00.000Z"}';
const obj = JSON.parse(s, (key, value) => {
  if (key === 'data') return new Date(value);
  return value;
});
console.log(obj.data instanceof Date); // true

// replacer: remover campos antes de serializar
const livro = { titulo: 'A', preco: 29.9, interno: true };
const publicJson = JSON.stringify(livro, (k, v) => (k === 'interno' ? undefined : v));
console.log(publicJson);

Boas práticas

  • Valide e trate erros ao parsear JSON.
  • Não confie em dados vindos do cliente. Faça validação do lado servidor.
  • Ao armazenar em LocalStorage/SessionStorage, armazene strings via JSON.stringify.
  • Evite serializar funções e referências circulares; o JSON só guarda dados, não código, e não entende objetos que se apontam.

Por que funções e referências circulares não funcionam

JSON não é um formato de código, é um formato de dados. Ele guarda apenas valores simples como strings, números, booleanos, arrays e objetos.

Funções não são gravadas em JSON. Se você tentar serializar um objeto com uma função, ela será ignorada:

const obj = {
  nome: 'Livro A',
  imprimir: function () {
    console.log(this.nome);
  }
};

JSON.stringify(obj);
// resultado: '{"nome":"Livro A"}'

Referências circulares acontecem quando um objeto contém uma propriedade que aponta de volta para ele mesmo (direta ou indiretamente). Isso cria um loop que o JSON não consegue representar.

const a = { nome: 'A' };
const b = { nome: 'B', pai: a };
a.filho = b;

JSON.stringify(a);
// TypeError: Converting circular structure to JSON

Nesse caso, o objeto a referencia b, e b referencia a. O JSON não tem como colocar isso em uma string simples.
