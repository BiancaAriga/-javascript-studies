Async / Await

Sintaxe moderna para código assíncrono — deixando as Promises mais legíveis.

O que é Async / Await?

async e await são palavras-chave do JavaScript (ES2017+) que permitem escrever código assíncrono de forma síncrona, mantendo a legibilidade. Elas funcionam com Promises por debaixo dos panos.

Ao invés de usar .then() e .catch(), você escreve como se estivesse esperando o resultado de forma linear:

Declarando uma função async

Uma função async sempre retorna uma Promise, mesmo que você não escreva explicitamente: 

// Função async simples
async function buscarLivro() {
  return { titulo: "Clean Code", autor: "Robert Martin" };
}

buscarLivro().then(livro => console.log(livro));

Neste exemplo, buscarLivro() retorna uma Promise resolvida com o objeto livro.

Usando await dentro de async

Dentro de uma função async, você usa await para "pausar" a execução até que a Promise seja resolvida: 

// Fetch com Promises (antiga forma)
fetch("https://api.exemplo.com/livros/1")
  .then(response => response.json())
  .then(livro => console.log(livro));

// Mesmo código com async/await (nova forma)
async function buscarLivroModerno() {
  const response = await fetch("https://api.exemplo.com/livros/1");
  const livro = await response.json();
  console.log(livro);
}

buscarLivroModerno();

Note: await só funciona dentro de uma função async. Tentar usar em escopo global dará erro.

Tratamento de erros com try / catch

Em vez de .catch(), use o bloco try/catch tradicional: 

async function buscarLivroComErro() {
  try {
    const response = await fetch("https://api.exemplo.com/livros/1");
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    const livro = await response.json();
    console.log("Sucesso:", livro);
  } catch (erro) {
    console.error("Erro:", erro.message);
  }
}

buscarLivroComErro();

Dica: O try/catch é mais parecido com código síncrono, facilitando o entendimento para quem vem de outras linguagens.

POST com Async/Await

async function criarLivro(titulo, autor) {
  try {
    const response = await fetch("https://api.exemplo.com/livros", {
      method: "POST",
      headers: {
        "Content-Type": "application/json"
      },
      body: JSON.stringify({ titulo, autor })
    });
    const novoLivro = await response.json();
    console.log("Livro criado:", novoLivro);
    return novoLivro;
  } catch (erro) {
    console.error("Falha ao criar:", erro);
  }
}

criarLivro("O Programador Pragmático", "David Thomas");

Aguardando múltiplas Promises

Use Promise.all() para aguardar várias requisições em paralelo: 

async function buscarVariosLivros() {
  try {
    // Fazer 3 requisições em paralelo
    const promises = [
      fetch("https://api.exemplo.com/livros/1").then(r => r.json()),
      fetch("https://api.exemplo.com/livros/2").then(r => r.json()),
      fetch("https://api.exemplo.com/livros/3").then(r => r.json())
    ];
    
    const [livro1, livro2, livro3] = await Promise.all(promises);
    console.log(livro1, livro2, livro3);
  } catch (erro) {
    console.error("Erro:", erro);
  }
}

buscarVariosLivros();

Promise.all() resolve só quando todas as Promises forem resolvidas. Se uma falhar, o catch captura.

Comparação: Promises vs Async/Await

Aspecto Promises (.then) Async/Await
Declaração function async function
Aguardar resultado .then() await
Tratamento de erro .catch() try/catch
Legibilidade Encadeamentos (callback hell) Linear, parecida com síncrono

Exemplo prático completo

// Simular uma API que retorna livros
function fetchFakerAPI() {
  return fetch("https://fakerapi.it/api/v1/books")
    .then(r => r.json());
}

// Usar async/await para consumir a API
async function exibirLivros() {
  try {
    console.log("Carregando livros...");
    const dados = await fetchFakerAPI();
    console.log(`Total de livros: ${dados.data.length}`);
    dados.data.forEach((livro, index) => {
      console.log(`${index + 1}. ${livro.title} — ${livro.author}`);
    });
  } catch (erro) {
    console.error("Erro ao carregar:", erro.message);
  }
}

exibirLivros();

Resumo

  • async declara uma função que retorna Promise;
  • await pausa a execução até a Promise resolver (só dentro de async);
  • try/catch trata erros de forma mais legível;
  • Código com async/await é mais fácil de ler e mantém;
  • Ainda usa Promises por baixo — é apenas açúcar sintático.
