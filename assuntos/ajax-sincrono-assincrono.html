AJAX síncrono vs assíncrono

Entenda a diferença entre fazer requisições que bloqueiam a página e requisições que rodam em segundo plano.

O que é AJAX?

AJAX é a técnica de usar JavaScript para fazer requisições HTTP sem recarregar toda a página. O navegador busca ou envia dados ao servidor e atualiza só o que precisa, deixando a experiência mais fluida.

Síncrono: bloqueia a página

Na versão síncrona, o JavaScript espera a resposta do servidor antes de continuar. Isso significa que o navegador fica parado até a requisição terminar. 

const xhr = new XMLHttpRequest();
xhr.open("GET", "https://jsonplaceholder.typicode.com/posts/1", false);
xhr.send();

if (xhr.status >= 200 && xhr.status < 300) {
  console.log(JSON.parse(xhr.responseText));
}

Repare no terceiro argumento de open(): false torna a chamada síncrona. Enquanto isso, o usuário não consegue interagir com a página.

Atenção: o uso de XHR síncrono no navegador é desencorajado. Ele bloqueia a interface e pode ser removido de alguns navegadores no futuro.

Assíncrono: continua rodando

A forma assíncrona dispara a requisição e deixa o navegador livre para seguir com outras tarefas. Quando a resposta chega, o código de callback ou evento é executado. 

const xhr = new XMLHttpRequest();
xhr.open("GET", "https://jsonplaceholder.typicode.com/posts/1", true);
xhr.onload = function () {
  if (xhr.status >= 200 && xhr.status < 300) {
    console.log(JSON.parse(xhr.responseText));
  }
};
xhr.onerror = function () {
  console.error("Erro na requisição");
};
xhr.send();

O valor true em open() é o padrão. Isso garante que a requisição não bloqueie o restante do script ou a interface do usuário.

Por que usar assíncrono?

  • O usuário não perde o controle da página.
  • Você pode mostrar indicadores de carregamento enquanto espera a resposta.
  • O navegador pode executar outras tarefas ao mesmo tempo.

Por isso, quase todas as APIs modernas usam assíncrono. Com fetch(), por exemplo, a Promise permite esse fluxo sem bloquear a página.

Resumo

  • AJAX síncrono bloqueia a página enquanto espera a resposta.
  • AJAX assíncrono permite que a página continue respondendo ao usuário.
  • Use sempre assíncrono para melhor experiência e desempenho.
  • O fetch() é uma forma moderna de trabalhar com AJAX assíncrono.
