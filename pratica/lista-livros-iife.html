Prática: lista de livros com IIFE

Estrutura base para você isolar variáveis e evitar poluição do escopo global.

O que você vai fazer

Reaproveite a mesma ideia da lista de livros, mas encapsule o código em uma IIFE. O objetivo é praticar escopo local e evitar que variáveis fiquem no ambiente global.

  • Crie uma IIFE para proteger as variáveis de uso global.
  • Use funções internas para carregar, renderizar e atualizar o status.
  • Evite expor elementos desnecessários para o escopo global.

Clique em carregar para buscar os livros.

    Observações

    Você pode usar a mesma API das etapas anteriores, por exemplo: https://openlibrary.org/search.json?q=romance&limit=15.

    A ideia é refatorar a lógica para ficar encapsulada dentro da IIFE.
