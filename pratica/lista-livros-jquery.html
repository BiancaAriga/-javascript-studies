Prática: lista de livros com jQuery

Estrutura base para implementar sua requisição $.ajax().

O que você vai fazer

Abstraia a requisição XHR usando jQuery — troque o código de XHR puro por $.ajax() ou $.get().

  • use $.get() para requisições GET simples.
  • Use $.ajax() para mais controle sobre a requisição.
  • Trate sucesso e erro com callbacks ou Promises.
  • Mostre um estado de carregamento enquanto a requisição está em andamento.

Clique em carregar para buscar os livros.

    Observações

    A API sugerida é https://fakerapi.it/api/v1/books?_quantity=10. Se preferir, use outra URL de API que retorne JSON.
