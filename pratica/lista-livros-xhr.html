Prática: lista de livros com XHR

Estrutura base para implementar sua requisição XMLHttpRequest.

O que você vai fazer

Crie uma requisição XHR para buscar livros de uma API e mostrar os resultados na tela. A base abaixo já inclui o botão, a área de carregamento e o lugar para renderizar os livros.

  • Use XMLHttpRequest com open(), send() e callbacks.
  • Trate sucesso e erro.
  • Mostre um estado de carregamento enquanto a requisição está em andamento.

Clique em carregar para buscar os livros.

    Observações

    A API sugerida é https://openlibrary.org/search.json?q=romance&limit=15. Se preferir, use outra URL de API que retorne JSON.
