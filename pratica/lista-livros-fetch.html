Prática: lista de livros com Fetch API

Estrutura base para você refatorar a requisição usando fetch().

O que você vai fazer

Substitua a lógica de XHR ou jQuery por fetch() para recuperar livros de uma API e mostrar os resultados na tela.

  • Use fetch() para fazer uma requisição GET.
  • Trate respostas OK e erros com .then() e .catch().
  • Mostre um estado de carregamento enquanto a requisição está em andamento.

Clique em carregar para buscar os livros.

    Observações

    A API sugerida é https://fakerapi.it/api/v1/books?_quantity=10. Se preferir, pode usar outra API que retorne JSON.
