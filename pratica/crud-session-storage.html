Prática: CRUD com Session Storage

Estrutura base para praticar persistência de dados na sessão do navegador.

O que você vai fazer

A ideia desta prática é persistir uma lista de livros na sessão do navegador, usando sessionStorage para armazenar, listar, atualizar e excluir itens.

  • Carregue livros da API ou use uma lista inicial.
  • Salve os dados no sessionStorage.
  • Crie operações de leitura, atualização e exclusão.
  • Mostre o estado da aplicação em tela.
