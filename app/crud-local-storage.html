Prática: CRUD com Local Storage

Estrutura base para praticar persistência de dados no navegador.

O que você vai fazer

A ideia desta prática é persistir uma lista de livros no navegador, usando localStorage para armazenar, listar, atualizar e excluir itens.

  • Carregue livros da API ou use uma lista inicial.
  • Salve os dados no localStorage.
  • Crie operações de leitura, atualização e exclusão.
  • Observe que os dados continuam disponíveis após fechar o navegador.

Clique em carregar para buscar os livros.

    Observações

    Você pode usar uma API para buscar os livros e depois salvar no localStorage. Compare o comportamento desta prática com o sessionStorage da Etapa 6.
